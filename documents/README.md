## 事实来源

文档按以下优先级描述系统：

1. Pydantic/API 契约和数据库模型；
2. Agent 编排、工具网关与 Core 业务实现；
3. 自动化测试；
4. 示例配置与界面文案。

模型能力、外部服务和测试结果均以“可选”“当前边界”或带日期的快照标注，不把配置开关写成永远在线的保证。

## 当前能力边界

- 在线对话入口使用持久化 Task Bundle；旧的单次请求和 Durable Task 接口仍保留。
- Jev 已接入在线装配，但只有在启用且配置 API key 后才参与分类或复核。
- 自然语言储蓄罐任务当前延期；结构化页面和 Core 接口仍可使用。
- Compose 当前只启动 PostgreSQL 与 Banking Core；Agent 和 PWA 需要单独启动。
- 仓库是模拟金融原型，不具备真实银行部署所需的完整安全与合规控制。

若文档与实现发生偏差，应以 Core 的金融状态和迁移后的数据库为执行事实，并在同一改动中更新对应文档。
